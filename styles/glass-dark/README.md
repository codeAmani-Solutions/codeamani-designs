# codeAmani Glass-Dark

The Hazina security console language: dark, data-dense operator UI.

- Canvas: deep navy `#070B14`, flat, no imagery
- Surfaces: liquid glass (4-6% white fill, 1px 12% white border, 18px blur)
- Accents: magenta `#FF2D95` for interaction, yellow `#FFE600` for selected / emphasis
- Status: mint `#2EE6A8`, amber `#FFA726`, red `#FF4D5E`, slate `#7C8BA5`
- Type: monospace throughout (JetBrains Mono stand-in), uppercase letterspaced microcopy, `// 01.1` section markers
- Shell: 242px sidebar, 22px gutter, 38px controls, 44px ledger rows
